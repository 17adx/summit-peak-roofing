# Summit Peak Roofing

Production-ready website template for a US roofing company built with Whop Websites, featuring Whop Payment Elements, Leads API, Setup Intents for card-on-file, and the Whop Invoices API.

## Features
- **Whop Payments & Elements**: PCI-isolated checkout with `PaymentElement`, `ExpressCheckoutElement` (Apple Pay / Google Pay), and `BrandingElement`.
- **Deposit & Final Balance Flow**: $500 project deposit with Setup Intent card-on-file, followed by Whop Invoices API final balance billing.
- **Leads API**: Instant lead creation from the estimate form.
- **Custom Tracking**: `whop.track` pixel events (`service_viewed`, `deposit_started`, `estimate_requested`).
